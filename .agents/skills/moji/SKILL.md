# 用 moji 写一幅书法

moji 是本仓库的代码书法生成器。字形取自开源书法字体，墨色、飞白、纸纹、印章由算法生成。命令行和网页用同一个引擎，同样的参数和种子写出同一幅字。

## 流程

1. **先给内容，确认后再出图。** 根据用户说的对象、场合、风格，推荐 2–4 条句子，标出推荐。每条写清：
   - 原文、作者、篇名，以及为什么适合；
   - 版式；
   - 落款：出处和受赠人；
   - 引首章两个字。

   等用户确认或修改后再出图。
2. **核对原文。** 每一条都用 `web_search` 搜一遍，以古诗文网、维基文库等权威来源为准，确认原文、作者、篇名。核对不了的不要推荐。
3. **出图。** 在仓库根目录运行：

   ```bash
   npm run render -- --text "正文" --src "出处" --to "受赠人" --from "署名" --lead "引首章" --format tiaofu --scale 3 --out "署名赠受赠人.png" --pdf "署名赠受赠人.pdf"
   ```

   命令输出一行 JSON，里面有 `seed` 和 `share`（分享链接）。
4. **自查。** 打开 PNG 看一眼：字有没有上下相撞，落款有没有压到正文，印章是否清楚。不满意就换一个 `--seed`，或者调 `--wild`。
5. **交付。** 给出 PNG、PDF 的路径和分享链接。

## 参数

| 参数 | 说明 |
|---|---|
| `--text` | 正文，可带标点。按标点会自动考虑「一句一行」；想手动分行，就在文字里放换行符 |
| `--src` | 出处，落款写成「录××」。格式是「作者 + 篇名 + 句」，如 `李白行路难句`；整首诗不加「句」，如 `李白静夜思` |
| `--to` / `--from` | 受赠人 / 署名。署名会刻成名章：三字名加「印」，两字名加「之印」，简体自动转繁体 |
| `--date` | 落款日期，默认按今天的干支和季节，如 `丙午秋` |
| `--lead` | 引首章，1–2 个字，最好从同一首作品里挑，带点巧思 |
| `--format` | 版式：`tiaofu` 竖条幅（两三行的句子），`doufang` 斗方（四字左右），`hengpi` 横披（字少排一行，或整首绝句） |
| `--wild` | 放纵度 0–1，默认 0.5。越大字越欹侧，大小反差越大 |
| `--scale` | 分辨率倍数，3 约等于 300dpi 印刷 |
| `--seed` | 随机种子，不给就随机 |

## 选句经验

- 按对象选：
  - 官员：勤政为民，如「从群众中来，到群众中去」「一枝一叶总关情」。
  - 工作：抱负，如「长风破浪会有时，直挂云帆济沧海」。
  - 失恋、看开：如「天涯何处无芳草」「也无风雨也无晴」。
  - 小朋友：如《咏鹅》。
- 网络用语里的「抽象」通常是**搞笑、有梗**的意思，不是哲学上的抽象。比如只写「鹅鹅鹅」三个字，就很有梗。
- 毛泽东的话要分清是诗词，还是文章、讲话，出处写准确。
- 刘建毛草的有些草书字形难认。送给不熟悉草书的人时，提醒一句。
